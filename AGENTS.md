# Agent Instructions

## Code Style

Follow the [Google Style Guide](https://google.github.io/styleguide/) for the language in use.

## Changes

- Surgical diffs only — fix the task, touch nothing else.

## After Code Changes

When this turn edits files, end the response with:

Suggested commit:
```
<type>: <short imperative summary>
```

Types: `feat`, `fix`, `refactor`, `docs`, `test`, `chore`. One line, focus on why.

Do not commit unless asked.
